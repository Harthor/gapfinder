Ask HN × Show HN × GitHub

Software people asked for, that nobody had built.

Every “Ask HN: is there a tool that…?” is a small, public signal of demand. gapfinder checks each request against everything launched on Show HN or published on GitHub before the day it was asked, and keeps the ones where nothing came close.

Strong gaps

Nothing close existed when they asked

The closest item scored below 0.60 on a 0–1 scale, and the replies in the thread did not point to an existing tool either. These are leads, not proof: they have not been reviewed by hand yet.

Method

How a request becomes a gap

Five steps over saved data. The search only looks at items created before each request, so the system cannot see the future.

    Evidence

    How much to trust it

    Each step was measured against cases with a known answer or checked by a person. The bar under each number is the 95% confidence interval: with samples this small, the true rate could be anywhere in the shaded range.

    The holdout is the honest number: when the method was run on ideas launched after a cut-off date, searching only what existed before it, a person confirmed only some of its “gaps” as real. Most had something partly similar. That is why a strong gap also requires that the people who replied did not name an existing tool.
